# 📊 Power BI Portfolio — Vitor Fonseca

Portfólio profissional de projetos desenvolvidos com **Power BI**, com foco em 
Business Intelligence, visualização de dados e relatórios analíticos.

🔗 **Demo:** [Abrir index.html no navegador]

---

## ✨ Funcionalidades

- ✅ Design **dark mode** moderno e responsivo
- ✅ Animações de entrada (Intersection Observer)
- ✅ Contadores animados de estatísticas
- ✅ Filtros de projetos por categoria
- ✅ Barras de habilidades animadas
- ✅ Modais de detalhes dos projetos
- ✅ Formulário de contato funcional
- ✅ Navbar com destaque de seção ativa
- ✅ Botão "Voltar ao topo"
- ✅ Menu mobile (hamburger)

---

## 📁 Estrutura

```
Portifolio/
├── index.html              # Página principal
├── assets/
│   ├── css/
│   │   └── style.css       # Estilos (Dark theme, responsivo)
│   └── js/
│       └── main.js         # Interatividade e animações
├── projects/
│   ├── project-1.pbix      # Dashboard de Vendas
│   └── project-2.pbix      # Análise Financeira
└── README.md
```

---

## 🚀 Como Usar

1. Clone o repositório
2. Abra `index.html` diretamente no navegador
3. Para os arquivos `.pbix`, abra com o **Power BI Desktop**
