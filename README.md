# Power BI Portfolio

Este é um portfólio que apresenta projetos desenvolvidos utilizando o Power BI. O objetivo deste projeto é demonstrar habilidades em visualização de dados e criação de relatórios interativos.

## Estrutura do Projeto

O projeto contém os seguintes arquivos e diretórios:

- **assets/**: Diretório que contém os arquivos de estilo e scripts.
  - **css/style.css**: Estilos CSS para a página do portfólio.
  - **js/main.js**: Código JavaScript para interatividade na página.

- **projects/**: Diretório que contém os arquivos dos projetos do Power BI.
  - **project-1.pbix**: Primeiro projeto do Power BI, contendo relatórios e dashboards.
  - **project-2.pbix**: Segundo projeto do Power BI, semelhante ao primeiro.

- **index.html**: Página principal do portfólio, que estrutura o conteúdo e inclui referências aos arquivos CSS e JavaScript, além de links ou visualizações dos projetos do Power BI.

## Como Configurar

1. Clone este repositório em sua máquina local.
2. Abra o arquivo `index.html` em um navegador para visualizar o portfólio.
3. Para visualizar os projetos do Power BI, utilize o Power BI Desktop para abrir os arquivos `.pbix` localizados na pasta `projects/`.
